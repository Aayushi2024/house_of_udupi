# 🍽️ House of Udupi

Welcome to **House of Udupi**! Yeh ek web-based project hai jo South Indian cuisine ki richness aur "House of Udupi" restaurant ke experience ko showcase karta hai. Is project mein HTML, CSS, aur JavaScript ka use karke ek engaging user interface banaya gaya hai.

🔗 **Live Demo:** [Click Here to View](https://aayushi2024.github.io/house_of_udupi/)

## 📂 Project Structure

Is repository mein main files ye hain:

- **`index.html`**: Website ka main structure, jisme menu sections, hero section, aur content layout shamil hai.
- **`momm.css`**: Website ki styling, themes, fonts, aur responsive design (Mobile/Desktop view) ke liye.
- **`momm.js`**: Interactive features jaise navigation toggle, dynamic content loading, ya animations handle karne ke liye.

## 🌟 Features

- **Authentic Theme**: Udupi culture aur food ko reflect karne wala design.
- **Responsive Layout**: Sabhi devices (Phone, Tablet, Desktop) par smoothly work karta hai.
- **Interactive Menu**: User-friendly navigation aur interactive elements.
- **Visual Appeal**: Attractive colors aur fonts ka use kiya gaya hai.

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
